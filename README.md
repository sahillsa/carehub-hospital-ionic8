# CareHub Ionic 8 Hospital App

CareHub is an Ionic 8 Angular app for hospital operations across admin, doctor, nursing staff, allied health professionals, support and facility roles, pharmacy, lab, and front desk teams.

## Run

Install dependencies, then start the Ionic app:

```bash
npm install
npm start
```

Or, if you have the Ionic CLI installed:

```bash
npm install
ionic serve
```

## Build

```bash
npm run build
```

The production web build outputs to `www`, ready for Ionic Capacitor packaging.

## Included

- Ionic 8 with Angular standalone components
- Role switcher for hospital teams
- Operational dashboard with metrics, patient queues, tasks, resources, and handover notes
- Patient, schedule, operations, and access views
- Search across the active role workspace
- Quick action modals for patient intake, handover, and escalation
- Responsive mobile and desktop layout
